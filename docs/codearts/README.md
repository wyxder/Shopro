## 一、评委 3 分钟核验路径

1. 读 [`01-使用总览.md`](./01-使用总览.md)：确认工具、时段、参与模块。
2. 读 [`02-全流程证据.md`](./02-全流程证据.md)：按"环境搭建 → 代码生成 → 调试排错 → 文档生成 → 评审整改"看真实产物与提交。
3. 读 [`04-调试排错记录.md`](./04-调试排错记录.md)：看至少 3 条"现象 → 定位 → 根因 → 修复 → 回归"的排错闭环。
4. 读 [`03-prompt-台账.md`](./03-prompt-台账.md)：看 Prompt 结构、迭代与采纳记录。
5. 看 [`screenshots/`](./screenshots/)：核对带时间戳的会话/编辑器截图。
