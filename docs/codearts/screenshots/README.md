## 二、拍摄规范

1. **时间可见**：系统时间或会话时间戳必须在画面内。
2. **任务可识别**：任务标题、打开的仓库名、目标文件路径至少出现两项。
3. **输入输出同框**：Prompt 与生成结果放在同一张图，避免只拍结果。
4. **人工修改可见**：至少一张图包含 diff/修改前后对比。
5. **不泄露密钥**：拍摄前关闭 `.env`、`key.txt`、控制台中的密钥输出；如已出现，必须打码并说明。
6. **不摆拍**：只截取真实发生的过程；无法提供的材料保持"待补"，不要用示意图替代。
