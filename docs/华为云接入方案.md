## 三、方案 A：OBS 承载视频与素材（必做 PoC）

### 3.1 目标架构

```text
浏览器
  │ 1. 申请上传凭证（携带 Supabase JWT）
  ▼
Edge Function: obs-sign-upload
  │ 2. 使用服务端 AK/SK 生成预签名 PUT URL（或 POST Policy）
  ▼
浏览器 ──3. 直传──▶ 华为云 OBS Bucket
                        │
                        ├─ 4. 记录 object_key 到 works / materials
                        └─ 5. CDN 回源播放（可选）
```

**关键原则**：AK/SK 只存在于 Edge Function Secrets，**绝不下发浏览器**；前端只拿短期预签名 URL。

### 3.2 资源与配置

| 项 | 建议值 | 说明 |
|---|---|---|
| Bucket | `shopro-ai-media` | 按环境加后缀 `-prod` / `-dev` |
| 区域 | 就近选择（如 `cn-east-3`） | 与主要用户群一致 |
| 存储类别 | 标准存储 | 视频访问频繁 |
| 目录规范 | `videos/{userId}/{workId}.mp4`、`covers/{userId}/{workId}.jpg`、`materials/{userId}/{uuid}.{ext}` | 便于生命周期与权限管理 |
| CORS | 允许站点域名，方法 `PUT/GET/HEAD`，暴露 `ETag` | 直传必需 |
| 防盗链 | Referer 白名单 + 签名 URL 有效期 15 分钟 | 防止资源被刷 |
| 生命周期 | 临时素材 30 天转低频/删除 | 控制成本 |

### 3.3 环境变量契约（新增到 `.env.example` 与 Edge Secrets）

```bash
HUAWEI_OBS_ENDPOINT=https://obs.cn-east-3.myhuaweicloud.com
HUAWEI_OBS_BUCKET=shopro-ai-media
HUAWEI_OBS_REGION=cn-east-3
HUAWEI_OBS_AK=            # 仅 Edge Secrets，禁止 VITE_ 前缀
HUAWEI_OBS_SK=            # 仅 Edge Secrets，禁止 VITE_ 前缀
HUAWEI_OBS_CDN_DOMAIN=    # 可选
```

> 安全红线：任何 `VITE_HUAWEI_OBS_AK/SK` 都会被打包进前端，禁止使用。密钥缺失时函数返回 503，不允许本地明文兜底。

### 3.4 最小验收（PoC 完成标准）

1. 通过 Edge Function 获取预签名 URL，浏览器直传 1 条 10MB 视频成功。
2. `works` 表记录 `storage_provider='obs'` 与 `object_key`，播放地址可访问。
3. 关闭 OBS 配置后，上传自动回退 Supabase Storage，业务不中断。
4. 未登录用户无法获取预签名 URL（401）。
5. 防盗链生效：非白名单 Referer 返回 403。
6. 截图：Bucket 对象列表、函数日志、上传成功页面、回退日志。

| 文件 | 变更 |

## 五、方案 C：CES + LTS 可观测性（建议）

| 指标 | 采集点 | 告警阈值（建议） |
|---|---|---|
| Edge Function 成功率 | 函数日志（结构化 JSON） | 5 分钟内 < 95% |
| P95 响应时延 | 函数/代理日志 | > 8s |
| 视频任务失败率 | `video_tasks` 状态 | 10 分钟内 > 10% |
| 支付回调失败 | `alipay-payment-notify` 日志 | 连续 3 次 |
| 扣费 RPC 错误 | PostgreSQL 日志 | 任意 1 次 |

接入方式：函数日志输出 JSON → LTS 采集 → CES 告警规则 → 通知群。现有代码已是结构化日志（如 `glm-5-3-flash` 的 `logProviderSwitch`），改造成本低。
